# Personal Portfolio Website

A modern and responsive personal portfolio website showcasing my skills, projects, education, experience, and achievements as a B.Tech Computer Science student.

## 🚀 About the Project

This portfolio is designed to provide a professional overview of my technical skills, academic background, projects, and development experience. It features a clean, responsive interface with an emphasis on usability and modern web development practices.

## ✨ Features

- Responsive and modern UI
- About Me section
- Education and academic background
- Technical skills showcase
- Projects and project details
- Experience and certifications
- Contact section
- Mobile-friendly design
- Deployed with Vercel

## 🛠️ Tech Stack

- React.js
- JavaScript
- HTML5
- CSS3
- Vercel

## 🌐 Live Portfolio

**Portfolio:** https://my-portfolio-website997.vercel.app

## 📌 Purpose

The website serves as my professional online presence and provides recruiters and developers with an overview of my technical capabilities, projects, and experience.
